# ObjectLab 3DGS — Third-Party 3D Assets

This file documents the **22 third-party 3D asset entries** referenced by the
ObjectLab 3DGS studio. It is intended for
repository attribution, academic research, and JPEG-related demonstrations,
presentations, publications, and dataset generation.

The 3D models originate from the **[Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)** collection. The model authors and copyright holders are identified individually below; **Khronos is the host/curator, not necessarily the copyright owner**.

**Important:** The ObjectLab HTML *references* these model files and loads them from their upstream URLs when selected. The model binaries and textures are not bundled in the HTML or this README. Listing a model does not establish that it was successfully downloaded, rendered, or used in any particular exported dataset. Each exported dataset should also record which model was actually used.

## Asset licences

- **[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)** (`CC0-1.0`): Creative Commons public-domain dedication. Model use, modification, and redistribution are generally permitted without a required attribution, although acknowledging the creator is appreciated.
- **[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)** (`CC-BY-4.0`): Permits copying, adapting, distributing, and commercial use, including research-related activities, subject to appropriate attribution, a licence link, and indication of modifications where applicable.
- **CC0 + CC BY 4.0**: Different portions or contributions to a model have different licences. Comply with the applicable terms of each contribution; when in doubt, provide CC BY 4.0 attribution for the complete asset.

**Model files and metadata can have different licences.** Check each model's authoritative `LICENSE.md` before redistribution. The upstream repository frequently licenses GLB/model content under CC0 while the explanatory metadata is CC BY 4.0. Rights in trademarks, logos, personalities, or other third-party material may not be covered by the Creative Commons grant.

## How the assets are used

The ObjectLab studio loads a selected GLB into a Three.js scene and can generate
synthetic RGB images, segmentation masks, calibrated camera trajectories,
COLMAP-compatible camera metadata, and train/test splits for 3D Gaussian
Splatting (3DGS) reconstruction experiments.

The studio may normalize model scale and orientation and place the asset on a
virtual stage. Lighting, materials, and viewpoint may also be changed by the
user. **These adjustments should not be represented as modifications by the
original asset authors.** Original model creators retain their respective
rights; the ObjectLab code's licence does not replace any asset licence.

When an asset is used in a manuscript, JPEG-related activity, demonstration,
or distributed synthetic dataset:

1. Identify the exact model(s) used and provide their original source URLs.
2. For **CC BY 4.0** models, credit the named creators, link to the licence, and
   note material modifications or adaptations, if any.
3. Preserve the upstream asset's licence/attribution material if distributing
   the GLB, textures, or a modified version.
4. If distributing a generated dataset, keep the applicable attribution and
   export manifest alongside the images. ObjectLab's dataset exporter can
   generate an `ASSET_CREDITS.txt` file and `capture_manifest.json`.
5. Review each model's upstream `LICENSE.md` again before a public release,
   especially when third-party trademarks, logos, or other protected content
   might appear in the render.
